# 月次資産レビュー 設計書（2026-07-12）

## 目的

マネーフォワードMEが持つ「資産の集計」は置き換えず、その上に無い
「**自分の投資方針に照らした月1回のレビューと助言**」を自動化する。
毎月1日の朝に、総資産スナップショット＋資産配分＋前月比＋AI助言をNotionに自動生成する。

## 方針（ユーザーと合意済み）

- **月次限定**。日次の資産総額表示は狼狽の元になるため作らない。
- マネフォの置き換えはしない（銀行連携等は不可能かつ不要）。
- 全自動運用：現金・ポイントは基準値で固定、投信は口数×指数推定＋毎月の積立を自動加算。
- ズレはマネフォPDFをもらった時点で実口数にリセット補正（2〜3ヶ月に1回推奨）。

## データソースと計算

### 1. 株式・ETF（実測）
既存の監視銘柄リスト（区分=保有）から `get_stock_data` で時価計算（米国ETFはドル円換算）。
※2026-07-12にマネフォ照合で保有を補正済み（VOO 3株・VYM 3株追加・SPYD単価6,509円）。

### 2. 投資信託・年金（口数×指数推定）
Notionの「**投信・積立マスタ**」DBで管理。1行=1ファンド（または現金・ポイント）。

推定式：
```
NAV推定 = 基準価額(基準日) × (指数現在値/指数基準値) × (ドル円現在値/為替基準値)  ※円建て指数は為替項なし
評価額 = 口数 × NAV推定 / 10000
```

連動指数のプロキシ:
| 連動指数 | ティッカー | 為替 |
|---|---|---|
| SP500 | ^GSPC | ×ドル円 |
| 先進国(除く日本) | TOK (iShares MSCI Kokusai) | ×ドル円 |
| 新興国 | EEM | ×ドル円 |
| 日経225 | ^N225 | なし |
| 全世界 | ACWI | ×ドル円 |

年金（iDeCo/DC・S&P500連動）は口数=評価額・基準価額=10,000の擬似口数方式で同式に載せる。

基準値: 2026-07-10終値（マネフォ基準価額の日付に合わせる）。セットアップ時に自動取得し
マスタの各行（指数基準値・為替基準値・基準日）に保存。

### 3. 毎月の積立の自動加算
- マスタの「月額積立」列（ユーザーがNotionで自由に編集可能）。
- 月次実行時: `追加口数 = 月額積立 / NAV推定 × 10000` を口数に加算し、マスタへ書き戻す。
- **二重加算ガード**: 「最終積立反映月」列に YYYY-MM を記録し、同月2回目以降はスキップ。
- 初期値は "2026-07"（7月分の買付はマネフォ基準口数に反映済みのため8月から加算開始）。
- 積立設定（2026-07時点）: SBI クレカ積立 月40,000円
  （S&P500 17,000／先進国 10,000／新興国 10,000／SBI・V・S&P500 3,000）。
  楽天は積立なし。iDeCoは国民年金全額免除期間中のため月額0（再開時に5,000へ変更）。

### 4. 現金・ポイント
マスタに区分=現金／ポイントの行として金額を保持（指数なし・固定値）。
ユーザーがNotionで随時編集可能。マネフォPDF受領時にClaudeが更新。

## 出力（毎月1日 朝7時ごろ）

1. **「資産推移」DB に1行追加**: 年月・現金・株式ETF・投資信託・年金・ポイント・合計・
   前月比%・リスク資産比率%。→ Notionのグラフ機能で推移チャート化。
2. **「📊 月次資産レビュー」ページ**を株レポート一覧DBに生成（種類=📊 月次）:
   - 総資産・前月比・リスク資産比率のカード
   - 資産クラス別の内訳表
   - AI助言（Groq）: 配分が方針（インデックス積立＋高配当の2本柱）とズレていないか、
     前月比の解釈、積立継続の観点。断定・煽りを避け、鮮度ルールとclean_ai_textを適用。
   - 末尾に「推定値である旨＋マネフォPDFで補正できる旨」の注記。

## 実行基盤

- `monthly_review.py`（新規）。既存 `daily_report.py` のヘルパー（get_stock_data,
  get_usdjpy_rate, clean_ai_text, HOLDINGS等）を再利用。
- GitHub Actions `monthly_review.yml`: cron `15 21 1 * *`（毎月1日 JST 6:15予約→7時前後着）
  ＋workflow_dispatch。遅延前提の前倒し予約は日次と同じ考え方。

## エラーハンドリング

- 指数取得失敗した行は前回評価額を使えないため「データなし」でスキップし合計に注記。
- マスタ書き戻し・行追加はbest-effort（失敗してもページ生成は継続）。
- AI失敗時は数値のみのレポートを出す。

## スコープ外

- 日次の資産表示／マネフォの自動取得（スクレイピング）／銀行残高連携
- 株主優待・配当カレンダー等の別機能

## 検証

1. セットアップ後、マスタの推定合計がマネフォ実績（投信9,073,654円）と±1%以内で一致すること
2. ローカルで月次実行→資産推移行とレビューページが生成されること
3. 同月2回目の実行で積立が二重加算されないこと
4. push後、8/1のクラウド実行で自動生成されること（ユーザー確認）
